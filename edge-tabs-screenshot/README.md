# Edge Tabs Screenshot All

現在のEdgeウィンドウで開いている全タブのスクリーンショットを自動取得し、ZIPファイルにまとめて保存するMicrosoft Edge拡張機能です。

## 機能

- **全タブ一括キャプチャ**: 現在のEdgeウィンドウ内の全タブを順番に処理
- **2つの撮影モード**:
  - **全体キャプチャ**: ページ全体をスクロールしながら撮影し、1枚の画像に結合
  - **表示範囲のみ**: 現在表示されている領域のみを撮影
- **ZIP保存**: 全タブ分の画像を日時付きZIPファイルにまとめて保存
- **メタデータ出力**: `metadata.json` と `summary.txt` をZIPに同梱
- **画像形式選択**: PNG / JPEG（品質指定可）
- **Lazy load対策**: 撮影前に一度ページ下部までスクロールするオプション
- **エラーハンドリング**: 1タブの失敗が他のタブに影響しない

## インストール手順

### 前提条件

- Windows版 Microsoft Edge (Chromiumベース)

### 手順

1. このリポジトリをクローンまたはダウンロードします
2. `edge-tabs-screenshot` フォルダをローカルに配置します
3. Edgeを開き、アドレスバーに `edge://extensions/` と入力します
4. 左下の「**開発者モード**」をオンにします
5. 「**展開して読み込み**」ボタンをクリックします
6. `edge-tabs-screenshot` フォルダを選択します
7. 拡張機能がインストールされ、ツールバーにアイコンが表示されます

## 使い方

1. Edgeで複数のタブを開いた状態にします
2. ツールバーの拡張機能アイコンをクリックします
3. ポップアップで設定を選択します:
   - **撮影モード**: 「全体キャプチャ」または「表示範囲のみ」
   - **画像形式**: PNG または JPEG（JPEGの場合は品質も指定可能）
   - **Lazy load対策スクロール**: ON/OFF
4. 「**スクリーンショット開始**」ボタンをクリックします
5. 各タブが順番に処理され、進捗が表示されます
6. 完了後、ZIPファイルの保存ダイアログが表示されます
7. 結果画面で成功・スキップ・エラーの件数と詳細が表示されます

## 出力ファイル

### ZIPファイル名

```
edge_tabs_capture_YYYYMMDD_HHMMSS.zip
```

### ZIPの中身

```
edge_tabs_capture_20240101_120000.zip
├── 01_example.com_ページタイトル.png
├── 02_github.com_リポジトリ名.png
├── ...
├── metadata.json
└── summary.txt
```

### 画像ファイル名

```
{タブ番号}_{ドメイン名}_{ページタイトル}.png (または .jpg)
```

- タブ番号は01から連番
- ファイル名に使えない文字は自動除去
- タイトルは80文字で切り詰め

### metadata.json

各タブの情報を配列で格納:

```json
[
  {
    "tabIndex": 1,
    "title": "Example Page",
    "url": "https://example.com",
    "hostname": "example.com",
    "captureMode": "full",
    "status": "success",
    "errorMessage": null,
    "capturedAt": "2024-01-01T12:00:00.000Z"
  }
]
```

### summary.txt

処理結果のサマリーをテキスト形式で記載。

## 制限事項

### スキップされるページ

以下のページはキャプチャ対象外としてスキップされます:

- `edge://` ページ（設定、拡張機能管理など）
- `chrome://` ページ
- 拡張機能ページ (`chrome-extension://`, `extension://`)
- `about:` ページ
- `data:`, `blob:`, `file://` URL
- `devtools://` ページ
- `view-source:` ページ

### 全体キャプチャの制限

- **fixed/stickyヘッダー**: 大きなfixed/sticky要素は撮影時に一時的にposition:absoluteに変更して対処しますが、完全には対応しきれない場合があります
- **Canvas高さ制限**: ブラウザのCanvas最大高さ (65535px) を超える非常に長いページでは、途中で切り詰められます
- **動的コンテンツ**: スクロール中にレイアウトが変わるページでは、画像に不整合が生じることがあります
- **無限スクロール**: 無限スクロールのページでは、Lazy load対策スクロールが長時間かかるか、すべてのコンテンツを読み込めない場合があります
- **描画タイミング**: アニメーションやトランジション中のページでは、キャプチャの内容が意図しないタイミングになることがあります
- **iframe内コンテンツ**: cross-originのiframe内のコンテンツはキャプチャに含まれますが、スクロール制御の対象外です
- **デバイスピクセル比**: 高DPIディスプレイでは画像サイズが大きくなります

### その他の制限

- 処理中にタブを閉じたり新しく開いたりすると予期しない動作になる場合があります
- 大量のタブ（数十個以上）を処理する場合、メモリ使用量が多くなります
- 認証が必要なページでログアウトされる等の副作用は考慮していません

## テスト手順

### 基本テスト

1. 3〜5個の通常のWebページタブを開く
2. 「表示範囲のみ」モードでキャプチャを実行
3. ZIPがダウンロードされ、中に画像・metadata.json・summary.txtが含まれることを確認
4. 各画像が正しく撮影されていることを確認

### 全体キャプチャテスト

1. スクロールが必要な長いページを含む複数タブを開く
2. 「全体キャプチャ」モードでキャプチャを実行
3. 長いページが1枚の画像に結合されていることを確認
4. 画像に重複やズレがないことを確認

### スキップテスト

1. `edge://settings` や `edge://extensions` などのシステムタブを含む状態でキャプチャ実行
2. システムタブがスキップされ、結果画面にスキップ一覧が表示されることを確認
3. summary.txtとmetadata.jsonにスキップ情報が記録されていることを確認

### 画像形式テスト

1. PNG形式でキャプチャを実行し、.pngファイルが生成されることを確認
2. JPEG形式（品質85%）でキャプチャを実行し、.jpgファイルが生成されることを確認
3. JPEGファイルサイズがPNGより小さくなる傾向があることを確認

### エラー耐性テスト

1. 通常のタブとアクセス不可のタブを混在させた状態で実行
2. エラーが発生しても他のタブの処理が続行されることを確認
3. エラー情報が結果画面とmetadata.jsonに記録されることを確認

## 技術情報

- **Manifest Version**: V3
- **外部依存**: JSZip 3.10.1（ローカル同梱）
- **API使用**: `chrome.tabs`, `chrome.scripting`, `chrome.downloads`, `chrome.storage`, `chrome.offscreen`, `chrome.windows`
- **ビルド不要**: 素のJavaScriptで実装、そのまま読み込み可能
